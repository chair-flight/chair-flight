# chair-flight

Aviation question bank app built with TanStack Start. Keep the AGENTS.md files current.
Before any task, read the AGENTS.md files that match it. This is mandatory, not optional.

- Any code change: `src/AGENTS.md`.
- Anything quesiton banks `content/AGENTS.md`, `content/question-bank-<bank>/AGENTS.md`, and `content/question-bank-<bank>/private.md`.
- use `/.external` as a work directory for any content you download to use as a reference or sources.
- use `/.workdir` for any code, or ephemeral projects that you develop that is not intended to end up in the remote.
